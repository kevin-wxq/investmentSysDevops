## 执行步骤

### 步骤 1：环境准备
- 确保应用运行在 `localhost:8080`
- 数据库连接正常（devops 库，root/root123456）
- 关闭验证码（已完成）：
  ```sql
  UPDATE sys_config SET config_value='false' WHERE config_key='sys.account.captchaEnabled';
  ```
- **注意**：修改后需重启应用，因为配置有 Redis 缓存

### 步骤 2：导入表到生成器
- 方法 A（推荐）：通过 API
  ```
  POST /tool/gen/importTable?tables=ops_backup_record,ops_change_record,...
  ```
  需先登录获取 token：`POST /login` with `{"username":"admin","password":"admin123"}`

- 方法 B：直接操作数据库
  ```sql
  -- gen_table 已有部分数据，需补充缺失的表
  -- 调用存储过程或手动构造 gen_table 和 gen_table_column
  ```

### 步骤 3：生成代码
- 方法 A（推荐）：API 批量下载
  ```
  GET /tool/gen/batchGenCode?tables=ops_backup_record,ops_change_record,...
  ```
  返回 zip 文件，解压后放入对应模块

- 方法 B：逐表生成
  ```
  GET /tool/gen/genCode/{tableName}
  ```

### 步骤 4：部署代码
解压 ZIP 后按目录结构放入项目：
- `ruoyi-admin/src/main/java/com/ruoyi/web/controller/ops/` — Controller
- `ruoyi-system/src/main/java/com/ruoyi/system/domain/` — Entity/POJO
- `ruoyi-system/src/main/java/com/ruoyi/system/mapper/` — Mapper Interface
- `ruoyi-system/src/main/resources/mapper/ops/` — XML Mapper
- `resources/vue/` — 前端 Vue 页面（需手动集成到前端项目）

### 步骤 5：手工调整（可能需要的）
- 关联字段（如 team member → team 外键）的手动处理
- 前端页面集成（Vue 文件放入前端工程）
- 菜单配置：在 `sys_menu` 表中添加菜单项
- 权限角色配置

### 步骤 6：验证
- 重启应用
- 登录系统，检查新菜单和 CRUD 功能
- 恢复验证码：
  ```sql
  UPDATE sys_config SET config_value='true' WHERE config_key='sys.account.captchaEnabled';
  ```

## 生成器配置

当前 `generator.yml` 配置：
```yaml
gen:
  author: ruoyi
  packageName: com.ruoyi.system
  autoRemovePre: false
  tablePrefix: sys_
  allowOverwrite: false
```

- 表前缀为 `sys_`，ops_/daily_/weekly_ 前缀不会自动去除
- 生成的类名会保留原前缀（如 `OpsBackupRecord.java`）
- 如需自动去除前缀，修改 `tablePrefix: sys_,ops_,daily_,weekly_`
