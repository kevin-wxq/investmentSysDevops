# 投资系统运维闭环管理平台 — 接口定义文档

> 版本：v3.0 | 分支：codex/devops-p1-linkage-hardening | 更新日期：2026-05-30
> 
> 基础路径：`http://localhost:8080`
> 
> 认证方式：Bearer Token（Header: `Authorization: Bearer {token}`）

---

## 一、认证接口

### 1.1 登录

| 项目 | 说明 |
|------|------|
| URL | `POST /login` |
| Content-Type | `application/json` |

**请求体：**
```json
{
  "username": "admin",
  "password": "admin123",
  "code": "验证码（captchaEnabled=true时必填）",
  "uuid": "验证码uuid"
}
```

**响应：**
```json
{
  "msg": "操作成功",
  "code": 200,
  "token": "eyJhbGciOiJIUzUxMiJ9..."
}
```

## 二、运维问题模块

基础路径：`/ops/issue`

### 2.1 查询列表

| 项目 | 说明 |
|------|------|
| URL | `GET /ops/issue/list` |
| 权限 | `ops:issue:list` |

| 参数 | 类型 | 说明 |
|------|------|------|
| pageNum | int | 页码 |
| pageSize | int | 每页条数 |
| issueNo | string | 问题编号（模糊） |
| issueTitle | string | 问题标题（模糊） |
| systemId | long | 关联系统ID |
| issueType | string | 问题类型 |
| status | string | 状态 |

### 2.2 查询详情

`GET /ops/issue/{id}`

### 2.3 新增

`POST /ops/issue/add`

### 2.4 修改

`PUT /ops/issue/edit`

### 2.5 删除

`DELETE /ops/issue/{ids}`

### 2.6 获取下一个编号

`GET /ops/issue/next-issue-no`

### 2.7 转Bug

| 项目 | 说明 |
|------|------|
| URL | `POST /ops/issue/{id}/convert/bug` |
| 权限 | `ops:issue:convert` |
| 说明 | 幂等操作，已转则返回已有Bug |

**响应：**
```json
{
  "msg": "操作成功",
  "code": 200,
  "data": {
    "id": 1,
    "bugNo": "BUG-20260530-001",
    "bugTitle": "...",
    ...
  }
}
```

### 2.8 转需求

`POST /ops/issue/{id}/convert/requirement` — 同上，幂等操作

### 2.9 导出

`POST /ops/issue/export`

## 九、仪表盘

基础路径：`/ops/dashboard`

### 9.1 统计数据

`GET /ops/dashboard/stats`

**响应字段：**
- totalItems — 总事项数
- unclosedItems — 未关闭数
- closedItems — 已关闭数
- overdueItems — 逾期数
- p0p1Items — P0/P1数
- issueCount / bugCount / reqCount / changeCount — 各模块计数
